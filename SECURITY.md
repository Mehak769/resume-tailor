# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of `resume-tailor` seriously. Because this application processes user resumes, job descriptions, and interacts with LLM APIs, preserving data privacy and preventing credential exposure is paramount.

If you believe you have discovered a vulnerability:

1. **Do NOT open a public GitHub issue.**
2. Send an email to **mehak.sharma@stud.th-deg.de** with the subject `[SECURITY] resume-tailor vulnerability`.
3. Include:
   - A description of the issue.
   - Steps to reproduce or a minimal proof of concept.
   - Potential impact.

We will acknowledge receipt within 48 hours and work with you to coordinate a responsible disclosure and patch release.
